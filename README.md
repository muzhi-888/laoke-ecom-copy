# laoke-ecom-copy · 电商商品文案生成器

> 局内人·老K · 专注实体老板 AI 落地实战

通用电商商品标题与卖点文案生成工具。按淘宝 / 拼多多 / 京东 / 抖音 / 亚马逊 / TikTok 各平台搜索逻辑差异化生成标题变体，做关键词三级布局，写五点卖点描述，跑违规词初筛。适用于电商平台卖家、运营与带货达人。

## 这个工具能做什么

- 按平台规则生成多套标题变体（不是一套标题通投所有渠道）。
- 提炼商品卖点，写五点描述（Bullet Points）/ 详情页卖点模块。
- 做关键词三级布局：核心词 + 精准词 + 场景词，覆盖搜索漏斗。
- 给出主图 5 张策略与详情页 8 段结构大纲。
- 标注文案里的违规风险词（极限词、虚假承诺、功效宣称），提示改写。
- 内置合规护栏，硬拒虚假宣传、极限词、侵权与刷单类请求。

## 目录结构

```
SKILL.md                  技能主文件（含完整使用指南）
_meta.json               元数据
references/              5 份领域知识（平台规则、关键词布局、违规词、卖点写法、主图详情页）
scripts/generate_title_variants.py   多平台标题与卖点生成（纯标准库，本地运行）
hooks/guardrail.md       合规护栏
icon.png                 技能图标
```

## 快速开始

```bash
# 跑内置演示，生成多平台标题与五点描述
python scripts/generate_title_variants.py

# 用你自己的商品信息（键值对文件）
python scripts/generate_title_variants.py product.txt out.md
```

输入格式（product.txt）：
```
name=316不锈钢保温杯
attr=480ml,一键开盖,礼盒装
sell=12小时保温,食品级材质,单手操作
scene=通勤,学生,上班族
platform=淘宝,拼多多,抖音
```
