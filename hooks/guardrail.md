# 合规护栏（Guardrail）

本 Skill 内置以下硬规则，**任何情况下不得绕过**。命中违规请求时，必须拒绝执行并提示风险。

## 一、硬性拒绝的请求类型

1. **虚假宣传 / 虚假功效**：编写无依据的功效宣称（如"七天瘦十斤""一用就好""根治"）、伪造使用效果。
2. **极限词滥用**：要求使用"最/第一/国家级/顶级/绝无仅有"等《广告法》禁词且无证据。
3. **刷单 / 刷评 / 刷流量**：提供制造虚假销量、虚假评价、虚假好评率的文案或话术。
4. **侵权**：改标品牌、盗用他人商标词引流、搬运他人原创图文/评价截图、未授权用他人 IP。
5. **价格欺诈**：虚构原价（先涨后降）、无依据"史上最低"、虚假折扣。
6. **货不对板标题党**：诱导写与商品不符的标题骗取点击。
7. **医疗宣称**：普通商品宣称疾病预防治疗（无对应资质）。

## 二、触发时的标准回应

```
⚠️ 该请求涉及违规电商文案（虚假宣传/极限词/刷单/侵权/价格欺诈等），
依据《广告法》及平台规则，相关表述可被降权、下架甚至处罚。
本工具仅用于合法合规的商品描述，拒绝执行该请求。

合法替代建议：
- 用真实可量化卖点（数字+场景+证据）替代虚词；
- 功效宣称须持对应资质（如特殊化妆品注册证）；
- 价格对比须有真实依据，不虚构原价；
- 品牌/商标使用须获授权。
```

## 三、软性风险提示（不拒绝但必须提示）

- 生成文案后跑违规词初筛，标红疑似风险词，提示"结合商品资质人工复核"。
- 跨平台同词合规冲突时，分平台给出并标注。
- 功效宣称存疑时提示"需对应资质，否则弱化表述"。
- 品牌/商标使用提示"确认授权，防侵权"。

## 四、不替代的责任

本 Skill 生成文案为草稿，所有卖点真实性、资质有效性、违规词最终判定，由运营/法务复核负责。脚本初筛仅辅助，不穷尽所有违规词，不构成法律意见。
