# 主图与详情页结构

标题负责"被搜到"，主图负责"被点开"，详情页负责"成交"。三者协同，偏科必输。

## 一、主图 5 张策略

| 图位 | 用途 | 最佳实践 |
|------|------|----------|
| 1 | 搜索展示主图 | 白底产品图，手机端可读 |
| 2 | 核心卖点 | 单一利益点，大字叠加 |
| 3 | 使用场景 | 真实场景应用 |
| 4 | 社交证明/数据 | 销量、奖项、认证 |
| 5 | 促销/行动号召 | 当前优惠，营造紧迫感 |

主图设计要点：
- 第 1 张决定搜索点击率，白底+产品清晰是底线。
- 第 2 张只讲一个卖点，别一图塞五个利益。
- 场景图要真实，别过度摆拍。
- 第 5 张促销信息须真实（见违规词文件，禁虚构原价）。

## 二、详情页 8 段结构

1. 核心卖点 Banner（3 秒抓注意）
2. 痛点场景 + 解决方案图
3. 产品规格与材质详情
4. 竞品对比图（间接对比，不点名）
5. 用户评价与口碑展示（须真实）
6. 使用说明与保养指南
7. 品牌故事与信任背书
8. FAQ（购买前 Top 5 疑虑）

## 三、详情页文案金句与转化钩子

每屏解决一个疑虑：
- 首屏：一句话利益 + 主图。
- 痛点屏：说出买家具体麻烦，制造共鸣。
- 方案屏：本品如何解决，配 FAB。
- 证据屏：检测/销量/评价（真实）。
- 对比屏：间接对比突出差异。
- 信任屏：品牌/资质/售后。
- FAQ 屏：预判疑问提前答。

## 四、短视频带货口播（抖音/快手）

30-60 秒结构：
```
开头钩子（3秒）：抛痛点或反常识
中段演示：实拍核心卖点
信任：检测/销量/评价一句话
结尾CTA：引导点击小车，给具体利益
```
要点：口播词与标题一致；场景真实；不夸大功效；前 3 秒定生死。

## 五、跨平台主图一致性

主图策略可跨平台复用（卖点一致），但第 5 张促销信息须按各平台活动真实填写，不虚构。母表（见 SKILL.md 二十八节）统管卖点，避免货不对板。

> 文案是链条工具：搜到靠标题，点开靠主图，成交靠详情。三块都到位，转化才稳。
